Doses/protocolos extraídos

+ Convidar aluno
Cadastre o nome e e-mail do aluno — ele mesmo cria a senha na tela de "Primeiro acesso".
+ Convidar vários alunos de uma vez
Um aluno por linha, no formato Nome, e-mail. Exemplo:
João Silva, joao@email.com
Maria Souza, maria@email.com
A catalogação exige banco de dados configurado (DATABASE_URL) para funcionar.
